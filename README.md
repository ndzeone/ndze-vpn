# Ndze VPN

Минималистичный VPN-клиент для Windows: VLESS / Reality, VMess, Trojan, Shadowsocks, подписки от Telegram-ботов, умная маршрутизация и карточка активности в Discord.

## Скачать

Открой **[Releases](../../releases/latest)** и скачай `NdzeVPN-Setup-<версия>.exe`. Установщик не требует прав администратора, .NET на компьютере не нужен.

## Обновления

Программа сама проверяет GitHub при запуске и раз в 6 часов. Когда выходит новая версия, в боковой панели появляется пункт **«Обновить до …»** и открывается окно со списком изменений.

После нажатия **«Обновить»** программа:

1. скачивает установщик и сверяет его SHA-256 с GitHub;
2. отключает VPN;
3. ставит новую версию поверх старой;
4. перезапускается.

Ключи, подписки и настройки сохраняются. Проверить вручную можно в **Настройки → Обновления**, там же отключается проверка при запуске.

## Первый запуск

1. Вставь ключ `vless://…` или ссылку на подписку в поле поиска на странице **Серверы** и нажми Enter. Ещё можно нажать **Ctrl+Shift+V** — ключ возьмётся из буфера обмена.
2. Для подписок из Telegram-ботов (stealthsurf, quattro-cloud и т.п.) открой **Подписки → Новая подписка**. Если по ссылке открывается веб-страница, а не список ключей, приложение само найдёт на ней ключи. Если не нашло, открой ссылку в браузере, скопируй `vless://` ключ и вставь его вручную.
3. Нажми круглую кнопку включения (или **Ctrl+Space**).

## Проверка ключа

Кнопка **«Проверка ключа»** в боковой панели (или **Ctrl+K**) показывает, что находится внутри ключа, ничего не сохраняя: сколько серверов, какие протоколы, сколько из них отвечает, остаток трафика и срок подписки. Понравилось — нажми «Добавить».

Принимаются:

| Что вставляешь | Примеры |
|---|---|
| Ключи | `vless://`, `vmess://`, `trojan://`, `ss://` — по одному или списком |
| Ссылки подписок | обычные, base64, **Xray JSON** (формат Happ), **sing-box JSON** (SFI, Karing, INCY), **Clash / Mihomo YAML** |
| Ссылки-импорты других клиентов | `happ://add/…`, `incy://…`, `hiddify://install-config?url=…`, `v2raytun://import/…`, `streisand://`, `sing-box://import-remote-profile?url=…`, `clash://`, `karing://` |

Панель может отдавать разное содержимое разным клиентам, поэтому приложение по очереди представляется несколькими популярными клиентами, пока не получит настоящий список серверов.

**Подписки с лимитом устройств.** Панели на Remnawave выдают ключи только клиенту, который сообщает идентификатор устройства, а остальным подсовывают одну заглушку «App not supported». Приложение отправляет такой идентификатор — он постоянный для компьютера и занимает один слот устройства, как любой другой клиент. Увидеть и скопировать его можно внизу окна проверки, а заменить — в `settings.json` (`DeviceId`), если нужно занять слот, уже зарегистрированный другим приложением.

Протоколы, которые ядро Xray не умеет (Hysteria2, TUIC, WireGuard), не добавляются молча: проверка отдельной строкой пишет, сколько таких серверов пропущено.

## Умное подключение

Через VPN идёт только заблокированное, остальное — через твой обычный IP. Порядок правил сверху вниз:

| Шаг | Куда | Что |
|---|---|---|
| 1 | как задашь | **Твои правила**: домены, IP, порты, программы |
| 2 | блок | QUIC (UDP 443), реклама (по желанию) |
| 3 | напрямую | локальная сеть, торренты, банки, Госуслуги, маркетплейсы, Яндекс, VK |
| 4 | VPN | YouTube, Discord, Instagram, X, Telegram, ChatGPT, Claude, Spotify… и реестр блокировок (`geosite:refilter`, `ru-blocked`) |
| 5 | напрямую | `.ru` `.рф` `.su`, `geosite:category-ru`, **любой российский IP** (`geoip:ru`) |
| 6 | VPN (настраивается) | всё остальное |

Российские домены резолвятся через российский DNS (77.88.8.8), остальные — через DoH 1.1.1.1. Каждый пункт можно выключить на странице **Маршруты**. Там же есть кнопка «Проверить», которая показывает твой прямой IP и IP через VPN.

### Режимы

- **Системный прокси** (по умолчанию) работает для браузеров и большинства программ. Права администратора не нужны.
- **TUN** — переключатель «Прокси / TUN» на экране подключения. Перехватывает весь трафик компьютера: игры, голосовые каналы Discord, лаунчеры. Windows один раз спросит права администратора. Правила вида «Процесс» (например, `cs2.exe` → напрямую) работают только в этом режиме.

## Активность в Discord

Discord показывает карточку только от зарегистрированного приложения, поэтому его нужно один раз создать самому:

1. Открой https://discord.com/developers/applications → **New Application** → назови его `Ndze VPN`. Это имя появится в строке «Слушает Ndze VPN».
2. Скопируй **Application ID**.
3. В приложении нажми **Discord** в боковой панели (или **Настройки → Интеграции → Настроить**), вставь ID и нажми **Сохранить**.

Загружать картинки в Discord не нужно: ключи `logo` и `shield` указывают на файлы из [`assets/discord`](assets/discord) в этом репозитории. Вместо них можно вписать любую https-ссылку на картинку.

В том же окне настраиваются тип активности («Слушает», «Смотрит», «Играет»), текст строк, полоса прогресса и кнопка, а справа показано живое превью карточки. Карточка появляется, только когда на этом же компьютере запущено десктопное приложение Discord.

## Дизайн

Три темы, переключаются сразу в **Настройках**: **Graphite** (тёмная), **Paper** (светлая), **Ink** (синяя ночь). Старые темы из 1.0 при обновлении автоматически заменяются на новые.

Боковую панель можно свернуть до узкой полосы с иконками кнопкой над меню. Состояние панели запоминается.

## Скорость и пинг

На экране подключения кнопка **«Замерить»** запускает настоящий замер: несколько параллельных потоков к публичному серверу (Cloudflare, при недоступности — Hetzner или OVH) идут через туннель. Первые секунды не считаются, пока соединение разгоняется, поэтому результат в Мбит/с близок к тому, что показывают обычные спидтесты.

Остальные цифры:

| Что | Как измеряется |
|---|---|
| **Задержка** | запрос через работающий туннель; соединение сначала прогревается, затем берётся лучший из трёх кругов, так что это RTT, а не время рукопожатия |
| **Пинг сервера** в списке | три TCP-рукопожатия к узлу, берётся лучшее (первое оплачивает DNS) |
| **Загрузка / Отдача** | счётчики самого Xray, включая трафик, который по умным правилам идёт мимо VPN |

## Стабильность

Программа не переключает сервер по одной неудачной проверке:

- проверка считается неудачной, только если туннель молчит, **а интернет на компьютере есть** (проверяется по российским сайтам). Уснувший ноутбук или пропавший Wi-Fi не трогают соединение;
- переключение происходит после нескольких неудач подряд (по умолчанию 3) и не чаще, чем раз в 10 минут. Оба числа меняются в **Настройках → Поведение**;
- если Xray падает, программа сначала перезапускает его на том же сервере, и только потом ищет другой. После четырёх падений подряд авто-перезапуск останавливается, чтобы не мигать бесконечно.

В режиме TUN права администратора запрашиваются **один раз за сессию**. Смена сервера, правок маршрутов и переподключение адаптер не трогают. Остановкой занимается тот же процесс, который его поднял, поэтому второго запроса прав при отключении нет, а если программа аварийно закроется, адаптер снимется сам. Если отказаться от запроса прав, программа не будет спрашивать повторно, а просто останется на системном прокси.

## Горячие клавиши

| | |
|---|---|
| Ctrl+Space | подключить / отключить |
| Ctrl+Shift+V | вставить ключ или подписку |
| Ctrl+K | проверить ключ |
| F5 | пинг всех серверов |
| Alt+← / Alt+→ | назад / вперёд |
| Enter / Del / F2 / Ctrl+C в списке серверов | подключить / удалить / переименовать / копировать ссылку |

## Где лежат данные

- `%APPDATA%\NdzeVpn\`: `settings.json`, `profiles.json`, `subscriptions.json`, `logs\`, `geo\` (базы правил, обновляются без прав администратора), `updates\` (скачанный установщик)
- `NDZEVPN_DATA=<папка>` — переменная окружения, с которой приложение хранит данные в другой папке (портативный режим)

## Сборка из исходников

Нужны .NET 8 SDK и Inno Setup 6:

```powershell
winget install Microsoft.DotNet.SDK.8
winget install JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File build\build.ps1
```

`build.ps1` делает всё по порядку:

1. скачивает Xray-core, sing-box, wintun и базы правил в `build\runtime`;
2. рисует иконки;
3. запускает self-test;
4. публикует self-contained сборку;
5. собирает установщик в `artifacts\`.

### Релиз

```powershell
powershell -ExecutionPolicy Bypass -File build\release.ps1 -Version 1.3.0 -Notes "• что нового"
```

Скрипт поднимает версию, собирает и тестирует проект, создаёт тег `v1.3.0` и GitHub Release с установщиком. Все установленные копии увидят обновление при следующей проверке.

### Self-test

`tests\NdzeVpn.SelfTest` проверяет работу на настоящих `xray.exe` и `sing-box.exe`, без VPN-сервера:

- разбор всех форматов ключей, base64-подписок и ключей из HTML-страниц;
- `xray run -test` для 6 типов узлов × 4 режима маршрутизации;
- `sing-box check` для TUN-конфига;
- живой Xray с заведомо мёртвым узлом: по access-логу проверяется, что Госуслуги, Сбер, VK, Habr и Ozon уходят в `direct`, а YouTube, Discord, Instagram, ChatGPT и X — в `proxy`;
- API статистики трафика.

### Скриншоты без окна

```powershell
NdzeVpn.exe --snapshot <папка>
```

Рендерит все страницы во всех темах в PNG из невидимого окна и завершается. Настройки не меняются.

### Устройство

```
src/NdzeVpn/
  Services/
    XrayConfigBuilder.cs   генерация конфига Xray: вся логика умной маршрутизации
    RoutingPresets.cs      встроенные списки (банки/госсервисы, заблокированные сервисы)
    GeoAssetService.cs     загрузка geoip/geosite + чтение списка тегов из .dat;
                           несуществующие теги отбрасываются, иначе Xray не стартует
    VpnController.cs       порядок запуска/остановки, авто-переключение сервера, подписки, Discord
    TunService.cs          TUN через sing-box + wintun (формат sing-box 1.13+)
    SystemProxyService.cs  системный прокси WinINET с восстановлением прежних настроек
    DiscordRpcService.cs   Discord IPC через named pipe, без зависимостей
    SubscriptionService.cs base64 / список / HTML-страница бота
  Themes/                  Graphite.xaml, Paper.xaml, Ink.xaml, Controls.xaml
  Views/                   Home, Servers, Subscriptions, Routing, Settings, Logs
build/                     fetch-deps.ps1, make-icon.ps1, build.ps1, installer.iss
```

Защита от «сломанного интернета»: при старте, выходе, выходе из сеанса Windows и удалении программы системный прокси сбрасывается, если он всё ещё указывает на уже не работающий локальный порт приложения.
